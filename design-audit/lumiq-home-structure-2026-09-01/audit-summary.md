# LumiQ 官网首页结构审查

审查对象：https://lumiq-home-pearl.vercel.app/en

## 当前结构

1. 首屏：品牌口号、三款产品合照、加入候补名单。状态：良好，但仍以产品为主。
2. Ola：单产品全屏介绍。状态：良好。
3. Tablet：单产品全屏介绍。状态：一般，开始与上一层重复。
4. Nest 15：单产品全屏介绍。状态：偏弱，第三次重复相同节奏。
5. 品牌理念：家庭场景、品牌短文、Learn / Connect / Care。状态：内容方向正确，但出现太晚，故事不足。
6. 收口：加入候补名单和页脚。状态：良好。

## 核心问题

- 连续三个产品楼层使用近似构图、卖点列表和按钮，首页像产品目录。
- 品牌内容到第五层才出现，而且依然用三款产品合照，不能真正改变浏览节奏。
- 缺少“为什么做 LumiQ”“产品如何共同服务家庭”“为什么值得相信”三类内容。

## 推荐结构：7 层

1. 品牌首屏：一句品牌主张、产品家族视觉、主行动按钮。
2. 品牌起点：为什么做 LumiQ，真实家庭痛点，Learn / Connect / Care。
3. 产品生态：三款产品放在一层，用角色关系说明各自解决什么问题。
4. 核心产品：只让主推的 Ola 保留一个完整产品楼层。
5. 家庭的一天：用早晨、放学后、夜晚三个生活片段串起 Ola、Tablet、Nest。
6. 信任与证明：安全隐私、儿童内容原则、团队、媒体评价或测试数据。
7. 加入与页脚：候补名单、品牌故事和产品详情入口。

## 备选结构

### 方案二：改动较小，8 层

首屏 → Ola → 品牌故事 → Tablet 与 Nest 合并 → 家庭场景 → 技术与安全 → 媒体评价 → 加入候补名单。

适合希望保留现有 Ola 楼层和大部分视觉素材的情况。

### 方案三：最精简，6 层

首屏 → 用户问题与品牌使命 → 三款产品总览 → 家庭场景 → 品牌与信任 → 加入候补名单。

适合官网首页只负责建立认知，把产品细节全部放到产品详情页。

## 结论

推荐采用 7 层方案。首页只保留 Ola 一个完整产品楼层，其余产品通过“产品生态”和“家庭的一天”出现；这样既不会削弱产品曝光，也能把品牌故事、使用场景和信任内容放进浏览主线。
