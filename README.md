## 环境说明

阅读图片、文档和视频不需要安装项目依赖。继续生成视觉稿需要新 Codex 自带的图片生成能力；继续生成视频需要可用的视频生成服务。`.libtv/project.json` 只记录原画布编号，不包含密钥，也不保证新账号拥有访问权。

完整迁移优先使用 GitHub 克隆，步骤见 `迁移与协作.md`。运行 `tools/打包给新Codex.sh` 仍可生成离线接力压缩包。
