# 品牌基线

以下内容来自 2026-07-22 品牌手册，适合作为视觉制作的起点。产品名称和口号以 2026-07-27 文档为较新依据。

## 品牌气质

品牌应同时具备：温暖、聪明、全龄、未来感、玩趣和好奇心。表达方式像一位懂 AI 的朋友：会讲故事、会倾听、会陪伴，但不过度拟人化或制造依赖感。

## 颜色

### 主色

| 名称 | 色值 | 用途倾向 |
|---|---|---|
| 珊瑚橘 Coral Play | `#FF6A4D` | 行动、玩趣、重点按钮 |
| 电光紫 Violet Spark | `#7B5CFF` | 科技、想象、光效 |
| 深墨黑 Ink Black | `#111111` | 专业、硬件、深色背景 |

### 辅色

| 名称 | 色值 | 用途倾向 |
|---|---|---|
| 阳光黄 Sunny | `#FFC93A` | 学习、能量 |
| 天空蓝 Sky | `#4FB6FF` | 陪伴、清透 |
| 薄荷绿 Mint | `#6DD3AA` | 成长、疗愈 |
| 蜜桃粉 Blush | `#FFB4C6` | 温柔、童趣 |
| 奶油白 Cream | `#FBF7EE` | 默认浅色背景 |

手册建议主色组合占整体视觉 70% 以上，辅色不超过 30%；同一画面内辅色不超过两种。

## 字体

- 英文标题：DM Sans Bold。
- 英文正文：Inter Regular。
- 中文：思源黑体 TC，常规与粗体。

落地到网站前，需要确认字体授权、加载方式和繁体／简体中文范围。

## 图形语言

- 播放三角：来自标志中 `i` 上方的珊瑚橘三角。
- 斜切色块：来自 `Q` 尾部的紫色切角。
- 圆润色点：表现玩趣和亲和感。
- 光晕射线：表现光、想象和全息体验。

## 标志使用

- 保留完整字标和足够留白。
- 只能等比缩放。
- 使用规定配色，并确保背景干净、对比清楚。
- 不随意变色、拉伸、旋转、加阴影或渐变，也不拆解字母。

现有仓库中的标志是带浅灰背景的 JPG，不是透明矢量母版。正式上线前应补充 SVG、PDF 或透明 PNG 标志文件。
