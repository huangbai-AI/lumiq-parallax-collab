# 首期网站范围

## 建议页面

| 页面 | 主要内容 | 首期优先级 |
|---|---|---|
| 首页 | 品牌定位、核心产品、技术、场景、故事、联系入口 | 最高 |
| 产品总览 | Tablet、Ola + Go、Print 及后续产品 | 高 |
| Ola + Go 详情 | 全息陪伴、全龄场景、外出延续、回家同步 | 高 |
| Tablet 详情 | 故事学习、ImagiMe、Story Quest、纯净体验 | 高 |
| Technology | AI 互动、显示技术、隐私与安全 | 中 |
| About Lumiq | 品牌故事、核心价值和愿景 | 中 |
| Support / Contact | 常见问题、联系、社交账号和合作入口 | 中 |
| Privacy / Terms | 隐私、条款和必要声明 | 待品牌方提供 |

Print 可在首期先放入产品总览和生态叙事；是否单独建立详情页，取决于可用产品图和购买流程。

## 首页建议结构

1. 首屏：一句话说明 Lumiq 与核心产品，主视觉优先使用 Ola。
2. 品牌理念：科技主动理解人的需要。
3. Ola + Go：从家中到外出的连续陪伴。
4. Tablet：安全、专注的儿童故事学习体验。
5. Print：把数字冒险变成可收藏的实体故事书。
6. 全龄使用场景：孩子、成人、长者。
7. 技术与隐私：全息、个性化、数据边界和安全说明。
8. 品牌故事与联系入口。

## 互动方向

飞书方案提出了四类方向：

- 图片叠层遮罩：通过鼠标或触摸揭示另一种产品状态。
- 图片与视频叠层：默认保持安静的产品图，互动时露出内部动态。
- 滚动叙事：让角色从二维画面进入 Ola，继续扩展到家庭与 Tablet 生态。
- 克制的极简排版：依靠网格、留白、清楚层级和少量进入动画讲清产品。

实时 3D 产品展示最适合 Ola 详情页首屏或产品探索区域，但不属于首期基础范围。只有在获得优化后的 3D 模型、贴图和性能预算后再决定是否加入。

## 首期不包含

- 购物车、支付、会员、订单和独立内容后台。
- 复杂数据库。
- 3D 建模和高复杂度实时互动。
- 大规模翻译、法律文件起草、长期搜索排名服务。
- 广告投放和社交媒体运营。
- 部署、域名绑定、服务器、HTTPS、CDN 和正式上线运维。

## 交付流程

需求与素材确认 → 信息结构与视觉方向 → 页面设计确认 → 响应式前端制作与动效 → 整站审核与集中修改 → 代码交付。

原方案提出素材确认后约一周完成首版，这一时间只适用于页面和素材及时确认、功能保持在纯前端展示范围内的情况。
