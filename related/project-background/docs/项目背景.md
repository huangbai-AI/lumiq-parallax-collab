# 项目背景

## 品牌定位

Lumiq Studio 希望把 AI 从“需要学习使用的工具”变成自然进入日常生活的陪伴者。品牌强调技术不替代家人、朋友或真实照护，而是让关心更容易表达，让提醒、倾听与协助在恰当的时候出现。

品牌名称来自 `Luminous + IQ`，分别代表光与智慧。最新品牌故事把核心归纳为四点：

- 温暖陪伴：有需要时回应，平时不过度打扰。
- 智慧理解：逐渐理解个人习惯，在合适时间提供合适帮助。
- 全龄关怀：针对孩子、成人与长者采用不同的互动方式。
- 未来生活：把学习、陪伴、提醒与家庭生活自然连成一体。

## 最新产品体系

### Lumiq Tablet

为儿童设计的 AI 学习与阅读平板，以故事、互动和想象力为核心。主要能力包括原创故事库、ImagiMe 面部融合、Story Quest 任务式阅读，以及无广告、无社交动态、无多余通知的专注体验。

### Lumiq Ola

个人全息 AI 陪伴装置，强调“一人一台”，不是全家共用的家庭中控。它通过自然对话、3D 全息角色、个人提醒和持续学习，适配孩子、成人与长者。

Ola 的三个主要角色是：

- 陪伴者：倾听、对话和鼓励。
- 个人助理：管理行程、待办与日常提醒。
- 长者生活照护伙伴：提醒用药、喝水、运动和休息。

### Lumiq Ola Go

Ola 随附的便携延伸装置，不是另一台独立 Ola，也不替代手机或手表。它在外出时保留熟悉角色、轻量互动、同步提醒、天气信息和语音日记；4G 版本可提供按需定位、撞击通知和 SOS。

回家后，Go 可吸附到 Ola，自动充电、同步一天的记录，并作为床头控制器和 AI 状态光圈。

核心信息：`One person. One Ola. Wherever life goes.`

### Lumiq Print

把 Lumiq Tablet 中通过 ImagiMe 生成的个性化故事制作成实体精装书，让孩子成为故事主角，并把数字体验转化为可保存、分享的成长纪念。

## 官网项目目标

官网需要把已有品牌识别、产品内容和页面层级统一起来，同时做到：

- 让海外用户快速理解 Lumiq 是什么。
- 先讲清楚产品与价值，再用视觉和互动增加记忆点。
- 同时表达未来科技感与家庭陪伴的温度。
- 建立可持续扩展的页面结构，方便以后加入新产品、内容和场景。

飞书方案将本项目定义为独立的 LUMIQ STUDIO 官网页面设计与前端制作；同一方案中还提到 Arpha，但两个品牌应作为独立官网执行，本仓库只收录 Lumiq 相关内容。

## 建议的叙事主线

首页可沿着“品牌理念 → 个人陪伴 → 产品生态 → 不同人生阶段 → 技术与隐私 → 品牌故事 → 联系方式”展开。

视觉上可以把深色区域用于硬件、AI、光学与全息体验，把奶油白或生活场景区域用于家庭、人物与情感。动效应服务于理解，不应让官网变成单纯的作品展示页。
