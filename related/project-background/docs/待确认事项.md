# 待确认事项

这些问题不会阻碍仓库建立，但在正式设计或开发前需要统一。

## 品牌与文案

- 对外标准写法是 `LUMIQ`、`Lumiq` 还是 `LUMiQ`。
- 主口号采用较新的 `A Light Through Every Chapter.`，还是品牌手册中的 `Play the Light.`；两者是否分别用于企业品牌与活动传播。
- 简体中文、繁体中文和英文的首期范围及默认语言。

## 产品命名

品牌手册中的 Beam、Pod、Play、Frame、Friends 与最新版文档中的 Ola、Ola Go、Tablet、Print 存在明显差异。需要确认旧产品线是废弃、重命名，还是仍会作为未来产品保留。

## 产品真实性与合规

- Ola、Ola Go、Tablet 与 Print 中哪些已经定型，哪些仍是概念或规划。
- Ola Go 的 4G、定位、撞击检测和 SOS 是否已确定为正式能力。
- 全息显示、AI 对话、儿童数据和长者照护相关表述可公开到什么程度。
- 隐私政策、儿童使用说明、安全声明和地区合规内容由谁提供。

## 网站制作

- 首期最终页面数量，以及 Print 是否需要独立详情页。
- 是否需要表单、邮件订阅、分析统计或多语言切换。
- 由谁负责部署、域名和后续维护。
- 是否有可用于实时展示的 3D 模型；如果没有，首期应使用现有高分辨率渲染图和视频。
