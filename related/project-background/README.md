# Lumiq Studio 官网项目

这是 Lumiq Studio 官网的项目资料仓库，集中保存品牌背景、产品定义、网站范围和原始视觉素材。

当前阶段是“资料归档与首期网站定义”。仓库暂未绑定具体开发方案；在页面设计、语言范围和发布方式确认前，不预设网站框架。

## 项目一句话

Lumiq 用温暖、易理解的 AI 产品，在孩子、成人与长者的不同人生阶段提供学习、陪伴、提醒与照护支持。

品牌主张：`Lumiq. A Light Through Every Chapter.`

## 最新产品体系

- **Lumiq Tablet**：面向儿童的 AI 学习与阅读平板。
- **Lumiq Ola**：一人一台的个人全息 AI 陪伴助理。
- **Lumiq Ola Go**：随 Ola 附带的便携延伸装置，让提醒、角色与生活记录在外出时继续。
- **Lumiq Print**：把孩子在 Tablet 中的个性化故事制作成实体精装书。
