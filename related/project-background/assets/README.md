- `product/ola/renders/black-background/`：11 张黑底高分辨率产品渲染。
- `product/ola/renders/transparent/`：与黑底版对应的 11 张透明背景渲染。

全部产品渲染均为 4200 × 2366 PNG，按 `1-1` 到 `5-3` 的原始编号保存，没有重新压缩或改色。

## 使用建议

- 页面合成、渐变背景和遮罩互动优先用透明版。
- 全屏深色产品展示可以使用黑底版。
- 不要把 4200 像素原图直接放进正式网页；发布时应另生成按屏幕尺寸分级的图片，并保留这里的原图不变。
- 现有渲染中的角色和界面仅作为当前素材使用，正式发布前要确认版权和最终界面。
- 目前没有 Tablet、Print、人物生活方式场景、SVG 标志或 3D 模型。
