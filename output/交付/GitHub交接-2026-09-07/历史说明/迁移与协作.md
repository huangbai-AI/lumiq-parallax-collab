# 迁移与远程协作

## 在新电脑恢复

```bash
git lfs install
git clone https://github.com/huangbai-AI/lumiq-parallax-collab.git
cd lumiq-parallax-collab
git lfs pull
```

打开仓库后，先让 Codex 阅读：

1. `AGENTS.md`
2. `当前进度.md`
3. `新Codex接力说明.md`
4. `沟通记录/README.md`

## 仓库组成

- 本仓库：全部视差滚动视觉资产、历史版本、提示词、当前静态稿、视频和原始产品素材。
- `related/website`：真实官网代码快照；来自 `codex/home-pearl-scroll-video` 的 `f12078b`。
- `related/project-background`：更早的 LumiQ 品牌资料、提案、网站方向和产品素材快照；来自 `ea3891c`。
- `沟通记录/`：与 LumiQ 相关的 Codex 可见对话文本，不含系统指令、推理、工具缓存和登录凭证。

## 日常协作

拉取最新内容：

```bash
git pull
git lfs pull
```

视觉、视频、提示词和 `related/website` 中的真实网站代码都可以直接在本仓库协作。原始仓库地址与导入版本记录在 `related/README.md`。

## 大文件说明

图片、视频、文档压缩包和三维文件使用 Git LFS。新电脑必须安装 Git LFS，否则看到的只是很小的指针文件。仓库不包含账号密钥、浏览器会话或在线生成服务的登录状态。
