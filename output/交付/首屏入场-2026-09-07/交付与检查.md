# 首屏 AI 字标入场与宽屏过渡

分支：`codex/lumiq-floors-1-2`，从 `5ffcac6` 继续。仅本地修改和提交，未推送、未部署。原项目 4198 视频试验版与 4193 代码版未改动。

## 采用的方案

- 首屏采用用户新提供并确认的 `1-bg.png`，原件归档于 `output/libtv/hero-intro-2026-09-07/source/hero-approved.png`（5504×3072）。按这张图保留 OLA 与 Tablet 正背面组合，不再以旧四款产品首帧覆盖用户选择。
- 先用 Lib Image 4K 档制作同构图无字背景参考，再由 Minimax H3 生成玻璃 LUMIQ 字母从左到右逐个浮现的视频。字母动画全部来自 AI 影片，没有用网页字体或代码逐字动画替代。
- H3 原片实际为 5.167 秒、2560×1440、24 帧。采用前 3 秒入场段，收紧为 2.4 秒；结尾以 0.24 秒融合回用户原图并短暂停留。网页成片 2560×1440、30 帧，H.264 / yuv420p，快速起播，无音轨，3,342,994 字节。
- 普通桌面首次进入播放一次；播放后显示用户原图。提前向下滚动可以跳过，倒回首屏及跨尺寸切换不会重播。视频报错、不能自动播放或等待超过 8 秒时显示原图，不阻止网页使用。
- 前两屏以轻柔上移和淡入淡出衔接，第二屏沿用原代码方案的角色图及已经生成的 Learn／Connect／Care 三张高清卡片。不再播放构图不匹配的旧 8 秒出舱视频。原代码比较入口 `?opening=code` 保留。
- 标题、导航、按钮与卡片文字仍为真实网页元素。导航与第三层之后的内容、素材和交互没有修改。

## 宽屏与小屏

- 图片保持完整构图。超出画面比例的两翼以浅紫珍珠色延伸，并根据实际留白连续增加左右渐隐，最大 96 像素，不再依赖原来的 2.1 比例门槛。
- 3808×1862 时左右渐隐约 84.94 像素，原先漏掉的比例已覆盖。上下也按图片自身边界柔化，避免普通桌面底部出现直线接缝。
- 小屏、短窗口、粗指针与减少动态模式继续原布局，不请求本次视频。

## 验证记录

- 完整构建通过：87 个页面；类型检查通过；16 项已有测试通过；三语言 886 个文案键检查通过。
- Chromium 实际测得入场播放中 `paused=false`，在 2.4 秒结束后 `paused=true`。前、中、尾及逐字过程已人工查看；无网页正文、导航或新字符混入视频，最终回到用户原图。
- 1440×900、1280×720、2560×1080、3808×1862、1024×768、390×844、844×390 来回切换，无横向溢出；小屏恢复原布局。
- 提前滚动跳过入场、倒回不重播、阻断视频请求时显示原图均通过；390 宽手机首次访问视频请求为 0；减少动态模式视频地址为空；`?opening=code` 不加载视频。
- 1440×900 第二屏三张卡片完整位于导航下方、屏幕以内；繁体中文与日文 1280×720 第二屏无溢出，三张卡片均存在。
- 第三层仍为五款卡片。滚到横移中点时卡片位移约 -608 像素（预期 -607.5），楼层固定在顶部；走完后再滚 250 像素，楼层正常移到 -250 像素。
- 以上为电脑 Chromium 与模拟屏幕验证；没有声称完成真实手机 Safari 或低性能设备验收。AI 原片局部产品细节存在生成式重绘，因此停留画面以用户原图为准。

## 查看与复现

- 当前本地预览：`http://127.0.0.1:4201/en`；首次打开或刷新可看入场。原代码比较：`http://127.0.0.1:4201/en?opening=code`。
- 独立视频：本目录 `LUMIQ玻璃字标入场.mp4`。
- 正式网页截图：`output/playwright/hero-intro-2026-09-07/`，首屏 1440 与 3808、第二屏、手机及繁体中文／日文截图。
- 源图、无字参考图、H3 原片、提示词与六帧走查：`output/libtv/hero-intro-2026-09-07/`。
- 在 `related/website/` 执行 `node scripts/prepare-hero-intro-assets.mjs` 可从归档素材重导出网页资源，不触发 AI 生成。需要现有 sharp 与 ffmpeg。
- 本地启动：在 `related/website/` 执行 `npm run build`，然后 `npm run start -- --hostname 127.0.0.1 --port 4201`。
